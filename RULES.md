# Devin Hack Kochi — event guidance

## Event guidance

The event is **Devin Hack Kochi**. Follow the organizers' current announcements
for participation format, eligibility, venue, schedule, and submission details.

Devin Hack Kochi has no major AI usage constraints. Participants may use Devin
and other AI tools, models, and providers. AI usage notes are project
documentation, not an additional event eligibility requirement.

## Project preparation and conduct

- Prepare the code repository, a short project description, and a working demo
  using [SUBMISSION.md](SUBMISSION.md) and the organizers' submission instructions.
- Document dependencies and data sources, actual checks, and known limitations.
- Be respectful of fellow participants and keep credentials and private data
  out of the repository and demo instructions.
- If maintaining an AI usage record, record the tools actually used and their
  contributions accurately.
